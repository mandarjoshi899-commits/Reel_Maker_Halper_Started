🎬 Reel Maker Helper 2.0

Your Idea. Your Story. Your Reel.

Reel Maker Helper is a beginner-friendly tool for Instagram Reels and YouTube Shorts creators. It helps users create video scripts, plan scenes, find music moods, and design thumbnail ideas.

✨ Features

- AI Reel Script Generator
- Emotional and Comedy Story Generator
- Scene-by-Scene Planner
- Music Mood Suggestions
- Background Suggestions
- Thumbnail Text and Design Helper
- User Login and Cloud Saved Scripts
- Hindi and Hinglish Support

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Supabase
- AI API Integration

📱 Platform

- Android Mobile Friendly
- Website
- Future Android App

Our goal is to make Reel creation easy for beginners and content creators.
